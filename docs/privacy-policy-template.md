# FairSplit Privacy Policy Template

Effective date: [Date]

FairSplit helps users track shared group expenses and settlements.

## Information We Collect

- Account information: name and email address.
- Group information: group names, members, invitations, and activity.
- Expense information: descriptions, amounts, categories, notes, payers, shares, and settlements.
- Phone invitation information: invited name, phone number, OTP status, and invitation code.

## How We Use Information

We use this information to create accounts, manage groups, calculate balances, send invitations, show activity, and help users settle shared expenses.

## Data Sharing

We do not sell personal information. Group members can see information related to groups they belong to.

## Data Storage

Data is stored using Supabase. Authentication is handled by Supabase Auth.
